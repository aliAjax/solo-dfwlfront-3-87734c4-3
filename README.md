# 集装箱拼箱装载核验台

- 行业：物流
- 技术栈：Vue3、Vite、TypeScript、Pinia
- 启动：`npm install && npm run dev`
- 构建：`npm run build`

## 功能

- 录入货物尺寸、重量、数量、可旋转方式（不可旋转 / 仅水平 / 六面自由）、危险品类别与堆码承重上限
- 自动装箱：按体积排序分配到多个集装箱（20GP / 40GP / 40HQ 可选），生成俯视装位图
- 约束核验：任一箱不超内体积、载重与堆码承重限制；底部支撑不足（<70%）拒绝落箱
- 危险品隔离：爆炸品单独装箱，氧化剂与易燃液体/固体等不相容组合自动换箱并给出原因说明
- 手动调整：俯视图中拖动货物实时重算利用率与重心，违反约束的移动被拒绝并高亮冲突货物；支持旋转 90° 与换箱
- 导出：最终装载清单 CSV 与各箱利用率 CSV（含重心偏移）
- 数据保存在浏览器 localStorage，刷新后货物与装位仍在；桌面与窄屏均可用
